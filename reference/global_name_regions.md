# List global-name regions

List global-name regions

## Usage

``` r
global_name_regions()
```

## Value

A character vector of available region identifiers.

## Examples

``` r
global_name_regions()
#> [1] "africa"        "east_asia"     "south_asia"    "middle_east"  
#> [5] "europe"        "latin_america" "north_america" "oceania"      
```
