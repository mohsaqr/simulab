# List learning-state categories

List learning-state categories

## Usage

``` r
learning_state_categories()
```

## Value

A character vector of available category identifiers.

## Examples

``` r
learning_state_categories()
#> [1] "metacognitive"    "cognitive"        "behavioral"       "social"          
#> [5] "motivational"     "affective"        "group_regulation" "lms"             
```
