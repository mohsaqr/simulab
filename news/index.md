# Changelog

## simulab 0.4.11

- Documentation: the `seed` arguments now state that a seeded call is
  reproducible and restores the session’s random-number state; examples
  that draw their own input data set a seed first; method references
  added to 22 generators and workflow verbs; network weight, direction
  and graph-model arguments documented with their defaults; fuller
  return-value descriptions for the specification, formula and
  event-trimming verbs; a categorical example for
  [`simulate_prediction()`](https://pak.dynasite.org/simulab/reference/simulate_prediction.md);
  package overview brought up to date.
